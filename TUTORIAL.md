# Сборка Ember для Android через GitHub

## 1. Репозиторий
Создайте на github.com новый **публичный** репозиторий `Ember-Android` и загрузите в корень всё содержимое
этой папки: `.github`, `app`, `build.gradle.kts`, `settings.gradle.kts`, `gradle.properties`, `.gitignore`, README, TUTORIAL.
Лучше через GitHub Desktop или git, чтобы скрытая папка `.github` точно загрузилась (инструкция та же, что для десктопа).

## 2. Секреты (обязательно)
**Settings → Secrets and variables → Actions → New repository secret**:
- `EMBER_API_ID` = ваш api_id
- `EMBER_API_HASH` = ваш api_hash

Не вставляйте эти значения в код, issues или чаты.

## 3. Запуск
**Actions → Build Ember Android → Run workflow.**
Первый раз собирается TDLib: 30-60 минут. Результат кэшируется, дальше сборка 5-10 минут.

## 4. Установка на телефон
Внизу запуска, блок **Artifacts → Ember-android**: скачайте zip, распакуйте, перекиньте `Ember.apk` на телефон и откройте его.
Разрешите установку из неизвестных источников. Для Redmi Note 14 Pro 4G нужна именно эта arm64-сборка.
APK подписан отладочным ключом, поэтому для обновлений устанавливайте новую версию поверх старой.

## 5. Если сборка упала
Раскройте красный шаг и пришлите последние 30-50 строк. Типичные места:
- **Build TDLib**: скрипты TDLib для Android (`build-openssl.sh`, `build-tdlib.sh`) могли поменять аргументы.
  В логе напечатаны их первые строки.
- **Build APK**: ошибка Kotlin в `Td.kt` обычно значит, что в свежем TDLib поменялось имя поля.

## 6. Ember-подарок: как проверить
Профиль (иконка справа вверху) → **Ember-подарок** → выбрать → **Применить**. Подарок запишется в конец био
невидимыми символами. Лимит био 70 символов (140 с Premium). Другой пользователь Ember увидит иконку подарка
в шапке вашего личного чата.
