# Ember для Android

Неофициальный клиент Telegram, написанный с нуля на Kotlin, Jetpack Compose и официальной библиотеке TDLib.
Чёрный интерфейс (OLED), оранжевый акцент.

Умеет: вход по номеру (код и пароль 2FA), список чатов, переписка текстом, непрочитанные,
профиль, **Ember-подарок**. Подарок выбирается из каталога Telegram бесплатно и показывается только
пользователям Ember. Формат метки совпадает с Ember Desktop, так что оба клиента видят подарки друг друга.

Пока нет: фото, видео и файлы (показываются подписью), голосовые, звонки, секретные чаты,
поиск, отправка медиа, пуш-уведомления. См. список в TUTORIAL.md.

Ключи `api_id` и `api_hash` не хранятся в коде: они задаются секретами GitHub.
Лицензия: GPLv3, как у TDLib-приложений на основе Telegram. Ember не связан с Telegram FZ-LLC.
